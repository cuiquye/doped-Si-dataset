# doped-Si-dataset
## Project Overview

This project focuses on a doped‑silicon dataset for training machine‑learning potential. Below is the description for each sub‑directory:

### Directory Descriptions

1. **1‑dataset**
Contains the training dataset and validation dataset for model development.
2. **2‑training**
Stores configuration files for training the machine‑learning potential, as well as the final trained potential function files.
